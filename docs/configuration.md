# Configuration

These settings change how the disassembly is laid out and what's in it. Put them near the top of the control file, after `from commands import *` (which makes `config` available):

```python
from commands import *

config.set_hex_dump(False)
config.set_show_cycles(True)
```

Each setting belongs to the current session, so `reset()` puts them all back to their defaults.

## Layout

| Setting                                    | Default   | What it does |
| ------------------------------------------ | :-------: | ------------ |
| `config.set_lower_case(b)`                 | True      | Lower case output (False for upper case). The command line's `--upper` and `--lower` do the same. |
| `config.set_indent_string(s)`              | 4 spaces  | The text for one level of indent. |
| `config.set_loop_limit(i)`                 | 32        | A label that's only used by a branch back to it from up to this many bytes later is a loop, and named e.g. `loop_c2002`. |
| `config.set_indent_loops(b)`               | False     | Indent the code inside those loops. |
| `config.set_inline_comment_column(n)`      | 70        | The column where comments at the end of a line start. |
| `config.set_word_wrap_comment_column(n)`   | 87        | The column where comments are word wrapped. |
| `config.set_blank_line_at_block_end(b)`    | True      | A blank line after the end of a block of code (e.g. after a jump or return). |
| `config.set_subroutine_header(s)`          | 87 `*`s   | The dividing line at the start of a subroutine's header comment (see `subroutine()`). |
| `config.set_subroutine_footer(s)`          | 87 `*`s   | The dividing line at its end. |
| `config.set_memory_region_headings(b)`     | True      | Group the memory locations at the top by region, with headings (see `memory_region()`). |

## What's shown

| Setting                                    | Default   | What it does |
| ------------------------------------------ | :-------: | ------------ |
| `config.set_hex_dump(b)`                   | True      | Show each line's address and bytes in a comment at the end of the line, e.g. `; 2000: a2 00       ..`. |
| `config.set_hex_dump_max_bytes(i)`         | 3         | The most bytes shown on a line of the hex dump (more are shown as `...`). |
| `config.set_hex_dump_show_ascii(b)`        | True      | Show the bytes as characters at the end of the hex dump. |
| `config.set_label_references(b)`           | True      | Before each label, a comment saying where it's used from, e.g. `; &2002 referenced 1 time by &200b`, and at the end, a list of the labels by how often they're used. |
| `config.set_show_char_literals(b)`         | True      | A comment with the character, for an immediate value that's a printable character, e.g. `lda #&41 ; 'A'`: for the 6502, in the text encoding (see `set_text_encoding()`), and for the 8080, in ASCII (and for LXI, only a value under 256). The Z80's instructions don't have them. |
| `config.set_show_cycles(b)`                | False     | Show how many cycles each instruction takes, e.g. `7/12` for a conditional jump (not taken/taken). It's shown in the hex dump, so only with `set_hex_dump(True)`. |
| `config.set_show_cpu_state(b)`             | False     | Show what's known about the registers and flags after each instruction (see [cpus.md](cpus.md#what-py8dis-knows-about-the-registers)). It's shown in the hex dump, so only with `set_hex_dump(True)`. |
| `config.set_show_autogenerated_labels(b)`  | True      | A list, at the end, of the labels py8dis named itself (e.g. `l1234`), as a to-do list of names to give. |
| `config.set_show_all_labels(b)`            | False     | A list of all the labels (for debugging py8dis). |
| `config.set_show_stats(b)`                 | True      | Statistics at the end: how much is code, data and strings. |
| `config.set_include_assertions(b)`         | True      | Assertions at the end, which make the assembler check that each expression given with `expr()` has the right value. |
| `config.set_redundant_instruction_comments(b)` | True  | Comment 6502 and Z80 instructions whose results are never used: `; Redundant instruction?` (see [cpus.md](cpus.md#redundant-instructions)). |

## Names and values

| Setting                                    | Default   | What it does |
| ------------------------------------------ | :-------: | ------------ |
| `config.set_label_return_instructions_numerically(b)` | True | Name a label on a return instruction `return_1`, `return_2` and so on. |
| `config.set_constants_are_decimal(b)`      | True      | Write constants (see `constant()`) in decimal by default (False for hex). |
| `config.set_upper_case_os_calls(b)`        | True      | Name the operating system's calls in capitals, as the manufacturer's documentation does: the Acorn MOS's (`OSBYTE`, `OSWRCH`, `GSINIT`), Commodore's Kernal's (`CHROUT`) and Commodore's other names (see [Commodore](machines/commodore.md#names)), and CP/M's `BDOS` and its functions (`C_WRITESTR`). False gives `osbyte`, `chrout` and so on. Set it before `acorn.bbc()`, `commodore.c64()`, `cpm.cpm()` etc., which name them. |
| `config.set_text_encoding(s)`              | `"ascii"` | How bytes are read as text: `"ascii"`, `"petscii"` or `"screen"` (Commodore screen codes). See [text-encodings.md](text-encodings.md). |
