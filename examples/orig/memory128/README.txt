memory128.orig (in examples/orig) is memory128, a memory game for the
C128's 80 column screen (the VDC), by Sebastian Dechert (2025), used as a
test of commodore.c128() (see python/memory128.py). It's distributed under
the BSD 3-Clause License (LICENSE, in this folder).

It is memory128.prg, unchanged, from

    https://github.com/radi0sus/memory128

at commit 60c1af97f1968fe6b6ed05708e72fb35720f068d (2026-06-14), where it
was assembled from memory128.asm with Kick Assembler
(https://theweb.dk/KickAssembler/). The labels in python/memory128.py are
from memory128.sym, the symbol file Kick Assembler made with it.
